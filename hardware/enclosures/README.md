# Корпуса MiniDash: параметрические макеты для примерки

Дата: 2026-11-05. Единицы: мм. Лицензия исходников: MIT.

Это настоящая твердотельная геометрия OpenSCAD для экспорта STL, но **не обмеренная
модель конкретной платы**. Печать образца возможна; совпадение с платой, стеклом,
разъёмами и автомобилем ещё не подтверждено. Не печатать весь комплект до примерки.

## Девять вариантов

Для `s3`, `cyd` и исследовательского `lite` есть три исполнения:

| Вариант | Конструкция | Назначение |
|---|---|---|
| compact | Скруглённая коробка + рамка на четырёх винтах | Стенд, универсальная основа под измеренное крепление |
| hood | Та же коробка + рамка с козырьком 12 мм | Проверка уменьшения бликов; угол обзора проверить на макете |
| panel | Та же коробка + рамка с фланцем 8 мм | Монтаж в отдельно измеренную панель/переходник |

`lite` - только механическое исследование. OLED, кнопки, прошивка STM32 и конечный
размер не выбраны. Эта модель не означает поддержку Bluepill проектом.

| Параметр | S3 | CYD | Lite |
|---|---:|---:|---:|
| Внешняя коробка, Ш×В×Г | 112×86×42 | 102×66×32 | 108×46×24 |
| Примерное окно, Ш×В | 50×38 | 59×45 | 60×20 |
| Стенка / дно / рамка | 2.4 / 2.4 / 2.4 | 2.4 / 2.4 / 2.4 | 2.4 / 2.4 / 2.4 |
| Зазор посадочного бортика на сторону | 0.35 | 0.35 | 0.35 |

**Все размеры в этой таблице - проектные допуски для макета, не результаты обмера.**
Для panel внешняя рамка больше коробки на 16 мм по каждой оси. Объём внутри
уменьшают стенки, стойки, бортик и выступающие компоненты. Высота корпуса с плоской
рамкой: `body_d + bezel_t`; козырёк требует отдельной проверки ориентации при сборке.

## Что уже есть и чего намеренно нет

Есть задний ввод кабеля (пример 7 мм), отверстия под стяжки для изолированного
носителя, четыре стойки с примерным пилотным отверстием 2.6 мм и ответными
отверстиями 3.4 мм. Тип винта и длину выбрать по купону и фактической глубине:
не считать пилот резьбой M3, не продавить дно. Внутренние полочки служат опорой
измеренному носителю. Слой изоляции обязателен; стяжки не должны давить на стекло.

Нет выдуманной сверловки PCB, готового посадочного места LM2596, окна USB,
выреза KCD11 и крепления к дефлектору Tiguan. Их положение зависит от реального
монтажа. Основной DC/DC разумно вынести в отдельный защищённый узел питания;
вмещаемость всех модулей в этих коробках не доказана. Чертёж автомобильного
крепления, прочность при ударе и тепловой режим не проверялись.

## Обмер и подгонка

1. Измерить PCB дисплея и контроллера, выступающие разъёмы/пайку, активное окно
   и наружные размеры стекла, высоту сборки и координаты монтажных отверстий.
2. Зафиксировать систему координат: вид на лицевую сторону, X вправо, Y вверх;
   ноль в центре окна. Записать положение USB, выключателя, ввода и антенны.
3. Изменить `body_*`, `window_*`, `cable_d`, `fit` в SCAD. Кромка рамки должна
   опираться на предназначенный для этого носитель, а не зажимать активное стекло.
4. Напечатать `coupon`, затем только рамку. Проверить винты, зазор, доступ к тачу.
5. Только после этого печатать основание и делать индивидуальный носитель плат.
   Не перекрывать антенну металлом/пучком проводов, оставить доступ к BOOT/RESET.
6. Проверить нагрев и жёсткость крепления на стенде, затем посадку в автомобиле
   без перекрытия обзора, органов управления и зон раскрытия подушек.

Начальные параметры слайсера: слой 0.2 мм, 4 периметра, 4-5 сплошных слоёв,
20-30% заполнения. Это отправная точка, не аттестация прочности. Compact/panel
печатать основанием/лицом рамки на стол; hood проверить в слайсере и при необходимости
развернуть/добавить поддержки. Бортик рамки и козырёк требуют осмотра слоёв.
PLA годится для комнатной примерки; для салона выбрать материал по его паспорту
и измеренной температуре установки, например подходящий ASA. PETG также нуждается
в тепловой проверке. Материал не заменяет проверку крепления и температур.

## Экспорт

```sh
openscad -o s3-compact-base.stl -D 'device="s3"' -D 'variant="compact"' -D 'part="base"' hardware/enclosures/minidash.scad
openscad -o s3-compact-bezel.stl -D 'device="s3"' -D 'variant="compact"' -D 'part="bezel"' hardware/enclosures/minidash.scad
openscad -o fit-coupon.stl -D 'part="coupon"' hardware/enclosures/minidash.scad
```

Для всех устройств/вариантов и проверки замкнутости: `python tools/export_enclosures.py`.
Нужны OpenSCAD, Python и `trimesh`. Итоги в `artifacts/local/enclosures/`;
STL и previews входят в отдельный пользовательский ZIP. Исходники хранятся в Git.
Художественные изображения корпусов - концепты дизайна; геометрию определяет SCAD/STL.
