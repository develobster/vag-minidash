# Проверка внешнего CAN-модуля без автомобиля — 18 октября 2026

## Основание

После ошибок автомобильного CAN и проверки целостности CTX→GPIO15 пользователь
измерил на модуле, при USB-only: V3/GND=3,2 В, концы R1 относительно GND=0 В
и 0,63 В, CTX/GND=3,27 В в ожидании. Эти измерения не выявляют очевидного
отключения передатчика или неверного питания, но не проверяют форму импульсов.
Назначение R1 как цепи Rs предполагается по монтажу типового модуля;
точная схема и осциллограммы конкретной платы не получены.

## Изолированный стендовый образ

Добавлен `MINIDASH_USB_CAN_BENCH` — CMake option, по умолчанию OFF.
При ON компилируется `can_usb_bench.c`; `main.c` вызывает только ограниченную
проверку и завершает app_main. Штатный CAN acquisition, дисплей и конфигуратор
в этом образе не запускаются. Рабочая прошивка не содержит тестовый вызов.

Это отдельный образ **usbcan18, только для USB при отключённом OBD**.
На старте 1 секунду слушает CAN и отказывается от теста при видимом трафике.
Отсутствие трафика не устанавливает физическое отключение автомобиля:
предварительное USB-only подтверждение пользователя обязательно.

Проверка: TWAI_MODE_NO_ACK, self reception, single-shot; 20 кадров ID 0x321
с изменяемыми данными, 500 кбит/с, GPIO15/GPIO5; проверяются ID, DLC, флаги
и данные принятого кадра. После проверки драйвер останавливается и удаляется.
Нет бесконечной передачи, OBD-запросов, UDS или записи ECU.
При новом старте стендового образа проверка повторится; его нельзя оставлять
установленным перед подключением к автомобилю.

Такой режим проверяет возврат передачи через внешний трансивер, а не только
счётчик принятия в очередь. Успех не доказывает работу на нагруженной
автомобильной линии и наличие ACK от другого узла. Неуспех на ненагруженной
линии без штатных терминаторов также не является достаточным основанием
для признания трансивера неисправным.

Стратегия соответствует описанию No ACK + Self Reception в
[официальной документации Espressif для legacy API](https://docs.espressif.com/projects/esp-idf/en/v5.4.4/esp32s3/api-reference/peripherals/twai.html).
Реально используется установленный ESP-IDF 5.5.5 с legacy driver/twai API.
Исходник новый, сторонний код и зависимости не копировались, лицензии сохранены.

## Сборка и восстановление

Сборка прежнего USB/UART пресета с `-DPROJECT_VER=usbcan18
-DMINIDASH_USB_CAN_BENCH=ON` прошла. Размер 231056 байт (0x38690), SHA-256
`dd5c1fd1d1ed60fc705b62a2c79509ccb0377129446ebb65f7507d4f36a26d8a`.
Исходный canerr18 (bin, ELF, описание проекта и таблица разделов) сохранён
до сборки в игнорируемом `.local/canerr18-restore/`; SHA-256 рабочего bin
`7e94c4a22cebbd603d73acb875196111a36ef03ad58532c1314b557b5d5bb7ef`.

Перед окончанием сеанса необходимо восстановить canerr18 только по 0x10000,
проверить digest, первые 64 КиБ и его запуск. Для следующей рабочей сборки
обязательно явно задать `-DMINIDASH_USB_CAN_BENCH=OFF`: CMake сохраняет option
в кэше даже при смене PROJECT_VER. Полное стирание и смена загрузчика не нужны.

## Фактический результат

usbcan18 записан только в приложение, digest проверен, первые 64 КиБ
сохранены. После управляемого USB-сброса получены все 20 совпадающих кадров:
`RESULT loopback=20/20`. Во всех строках errors=0, TEC=0, REC=0.
Тест остановился с ESP_OK, app_main завершился. Действительно выполнена
проверка GPIO15 → внешнего трансивера → GPIO5, без автомобиля и ACK.
Неисправность модуля под нагрузкой автомобильной линии этим не исключена.
Журнал/manifest локально: `.local/flash-obd-live-20261018-163542/`.

Восстановлен **исходный canerr18** из сохранённого bundle с исходным SHA-256,
не стендовый образ. Esptool verify_flash подтвердил digest; первые 64 КиБ
остались побайтно равны. Журнал/manifest:
`.local/flash-obd-live-20261018-163931/`. До обеих записей сохранены свежие
полные копии 0..0x30ffff и приложения в `artifacts/hardware/`.
Дополнительно выполнена успешная сборка штатного пути с bench=OFF;
в кэше build-каталога оставлено OFF. Эта пересобранная копия не записывалась:
на устройстве именно ранее принятый canerr18.
После управляемого сброса восстановленного образа за 18 секунд подтверждены
canerr18, standard_obd=on/UDS=off, ST7789, UI ready и калиброванный тач;
panic/watchdog/brownout не обнаружены. В пересобранном штатном bin отсутствует
стендовая строка USB-ONLY BENCH IMAGE, CMakeCache подтверждает bench=OFF.

Следующая проверка требует физического ввода: при отключённых USB и OBD
прозвонить CANH модуля до контакта 6 отсоединённого OBD-штекера и CANL до 14.
Рабочий локальный loopback не проверяет кабель и контакт с автомобильной
шиной. Обрыв одной жилы нельзя исключать лишь по большому числу RX.
Живые автомобильные значения остаются неподтверждёнными.
